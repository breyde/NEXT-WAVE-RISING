# Next Wave Rising Android wrapper

Test build: a lightweight Android WebView container that opens the published Next Wave Rising site:
https://breyde.github.io/NEXT-WAVE-RISING/

This is an isolated APK build test on the public repository branch `test-next-wave-android-apk`.
It does not replace or modify the website's main branch or its existing automation.

Build output: `app/build/outputs/apk/debug/app-debug.apk`.
