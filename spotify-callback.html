Conectar Spotify

Autoriza Next Wave Rising para gestionar tus playlists temporales privadas y actualizar el contenido de tus playlists públicas. Esta página utiliza OAuth con PKCE; no necesita tu contraseña ni el Client Secret.

Procesando la autorización de Spotify…

No lo publiques ni lo envíes por mensajes. Pégalo directamente en GitHub → Settings → Secrets and variables → Actions, con el nombre SPOTIFY_REFRESH_TOKEN. Después puedes cerrar esta página.
